API Concierge – Administração de Visitantes

API desenvolvida em Node.js para gerenciamento de visitantes em sistemas de portaria/concierge, com integração a banco de dados MySQL.

📌 Descrição

Esta API tem como objetivo centralizar e facilitar o controle de entrada e saída de visitantes, oferecendo endpoints para cadastro, consulta e gerenciamento de registros.

O sistema é voltado para uso em portarias de condomínios, empresas ou ambientes controlados, permitindo maior organização, segurança e rastreabilidade das informações.

⚙️ Tecnologias utilizadas
Node.js
Express
MySQL
dotenv (variáveis de ambiente)
Nodemon (ambiente de desenvolvimento)
